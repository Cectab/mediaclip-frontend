MediaClip - Seed sample data

One-tap tool to add ~20 realistic Botswana media mentions to your currently-logged-in client account. Uses your existing login session. Safe to run more than once (adds a new batch each time).

What this does: Posts 20 realistic Botswana media mentions (mix of print, radio, broadcast, social, in English and Setswana, with sentiment scores) into your client account via POST /api/analyst/clips. Refresh your dashboard afterwards to see the numbers.

Cleanup: Before onboarding real BIHL staff, click "I'm done testing" for a one-line SQL command you can run in Neon's SQL editor to delete every seeded row in one go.
